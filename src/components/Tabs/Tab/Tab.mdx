## Props

Other props, such as `data-*` attributes, are forwarded to the `button`.

Inside `Tabs`, `role`, `id`, `aria-selected`, `aria-controls` and `tabIndex` are set by `Tabs`.

An `onClick` runs before the tab is selected.

The `badge` text is part of the tab name.
