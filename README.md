# Tabs & Badge — Design System components
  
Accessible and reusable React components for a design system:  
Tabs (variants: pill & underline) and Badge.  
  
_🚧 Work in progress 🚧_
  
## Getting started
  
Requires Node 24 and pnpm.
  
## Install and run

```bash
# Install dependencies
pnpm install
  
# Demo page
pnpm dev

# Run Storybook
pnpm storybook

# Tests
pnpm test

# Type check
pnpm tsc

# Lint and format (Biome)
pnpm check
```
